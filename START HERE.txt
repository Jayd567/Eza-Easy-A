EZA - a programming language for games, apps and everyday tools
================================================================

Everything here is ready to use. Nothing needs to be compiled.
You need 64-bit Windows 10 or 11.

1. INSTALL
   Double-click install.bat.
   (If Windows says "Windows protected your PC", click "More info" -> "Run anyway".
    That appears because the program isn't signed; it's safe.)

2. TRY IT
   Open a NEW terminal (PowerShell or Command Prompt) in this folder and run:

       eza examples\menu.eza        a menu with music, then a little game
       eza examples\budget.eza      a budget app with charts and a database
       eza run examples\everyday.eza

   Or just type  eza  to get a prompt where you can type code line by line.

3. LEARN
   Open EZA_GUIDE.md - it explains every part of the language, from your first
   print to 3D worlds. (VS Code shows it nicely: right-click it -> Open Preview.)

4. WRITE YOUR OWN
   Make a file ending in .eza (in VS Code you get colors, hints and error squiggles),
   then run it with:  eza yourfile.eza

   Useful commands:
       eza check yourfile.eza    find mistakes without running
       eza test                  run your tests
       eza build yourfile.eza    make a .exe you can share with friends

What's in this folder
   eza.exe          Eza itself (the whole language and engine in one file)
   install.bat      sets Eza up for you      uninstall.bat   removes it again
   EZA_GUIDE.md     the complete beginner's guide
   README.md        a short overview
   examples\        example programs with their pictures and sounds
   vscode-eza\      the VS Code extension (install.bat installs it)
